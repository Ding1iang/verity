# 证据规则

> 结论只能比证据小。本文件定义什么算证据、证据有多硬、什么时候作废。

## 1. 假结论的六个来源

六种形态覆盖了“没验却说验了”的绝大多数情况。看到任何一种，按最后一列直接判死。

| 编号 | 形态 | 长什么样 | 为什么像真的 | 判死规则 |
|---|---|---|---|---|
| F1 | 以偏概全 | 一张局部截图、一个样本、一次成功，就断言整页、整流程或全量正常 | 被拍到的那部分确实是真的 | 证据覆盖范围小于结论范围，超出部分按 C 级；整条结论判“未通过（证据不足）”，补足覆盖后才可重判 |
| F2 | 旧证据复用 | 拿上一次构建、上一个版本或上一轮会话的结论交差 | 证据本身真实，当时也确实通过 | 版本、环境、数据任一锚点变化即作废；复用须同锚点并抽样复算，否则判未通过 |
| F3 | 未跑先断 | “应该没问题”“逻辑上看是对的”“按经验不会出问题” | 推理可能完全正确 | 无执行读数即 C 级；C 级不能判通过，只能提出假设并安排取证 |
| F4 | 未验写成通过 | 验收项没做或只做了一半，结论栏却写“通过” | 其他项都过了，看起来只差一点 | 该项无达标证据就不得写通过；只能记待验、阻塞（举证单齐全）或未通过 |
| F5 | 没试过写成阻塞 | 不会做、没环境、没时间，直接写“阻塞” | 确实遇到了困难 | 阻塞必须过举证门槛（见 `acceptance.md` 第 4 节）；缺一个维度或没有正对照，按未通过记 |
| F6 | 多口径 | 对话说“全过”、提交说“基本完成”、文档说“部分待验” | 每一处单看都合理 | 以 07 账本为唯一状态源；对不上时以账本为准，并把该次交付判为未通过（口径未收口） |

## 2. A / B / C 三级

### A 级：独立、可复算的读数

**定义**：换一个人、换一台机器，按记录的命令、步骤和输入重跑，能得到同一结果；或者由系统直接产出的机器读数。

**必须带四个定位**：

1. 命令或操作：完整可执行，不写“测过了”。
2. 输入与夹具：用了什么数据、什么账号状态、什么前置条件。
3. 环境：系统、运行时、依赖版本、设备或服务。
4. 时间与版本：什么时候、对哪个 commit 或构建号取的。

**合格例子**：测试命令的退出码与汇总行；构建产物 hash；接口响应体；数据库查询结果；像素或布局读数；性能采样文件。

**不合格例子**：只在对话里转述的数字；没有命令和输入的“已经验证”；无法重跑的临时手工操作；只贴一行成功日志。

### B+ 级：两路现场观察互证

**定义**：两条互相独立、通道不同的现场观察同时支持同一结论，例如界面读数加网络响应、界面读数加存储记录。单张截图换裁剪、同一份日志换两行，不算两路。

**合格例子**：按真实入口操作后看到列表新增一条，同时在数据库查询到同一主键；页面显示保存成功，同时接口返回 201 且响应体含新 ID。

**不合格例子**：同一张截图的不同区域；同一日志的两行；先看界面、再复述界面。

**账本记法**：两路 B 级互证记 `B+`；只有一路记 `B`。

### B 级：现场观察

**定义**：人（或代理）当场在真实界面或真实运行环境看到的单一现象。

**必须带的信息**：页面或区域、操作路径、观察时间、被测版本。声明范围不得超过实际看到范围。

**合格例子**：按原始入口实际点击后读到的界面文本；报错弹窗；带完整操作路径的渲染画面。

**互证规则**：两类不同通道的 B 级观察可以互证判通过，例如界面读数加网络或存储读数。同一张截图的不同裁剪、同一份日志里的两行，不算两类。

### C 级：推断与自述

**定义**：代码阅读、静态检查、日志“没报错”、模型或执行者自述、他人转述、过期材料、没有操作路径的单张截图。

**用途**：只能提出假设、决定下一步取证，永远不能作为“通过”的依据。

> 分级只看证据本身，不看说这话的人是谁。资深工程师的口头保证仍是 C 级；一条能复算的命令输出，即使是新手跑的，也是 A 级。

**账本记法**：单条证据记 `A`、`B` 或 `C`；两条不同通道的 B 级互证记 `B+B`；没有证据记 `—`。账本不写“高/中/低”，置信度只出现在结论文档里。

## 3. 判通过的最低证据

默认门槛：**1 条 A 级，或 2 条不同通道的 B 级（账本记 `B+B`）**。下表是各结论类型的加严要求，就高不就低。

| 结论类型 | 最低证据 | 说明 |
|---|---|---|
| 功能行为 | 1 条 A，覆盖声明的全部入口与关键分支 | 快乐路径之外，边界和失败路径各至少 1 次 |
| 界面与视觉 | 覆盖声明范围的全景 B 加局部 B，或像素读数 A | 单张局部截图最多支撑它拍到的那个区域，不能支撑整页 |
| 数据、存储、迁移 | A 级读数加迁移前后数据比对加回滚或恢复验证 | 只证明“能写进去”不算通过 |
| 性能与容量 | A 级采样：同环境、同夹具、至少 3 次并写明分布与阈值 | 单次最快值不算结论 |
| 安全、权限、破坏性操作 | A 级读数加正对照加负对照 | 越权或异常输入必须被拒，且拒绝可复算 |
| 兼容与环境矩阵 | 每个声明支持的组合各 1 条证据 | 没测的组合从声明里删掉，不能默认“应该兼容” |
| 文档与配置 | 按文档从零执行一遍的 A 级记录，或 2 条独立 B | 只读一遍文档不算验证 |

**全称结论加严**：凡出现“全部”“所有”“都”“任意”，必须覆盖全部样本，或给出抽样方案和置信说明；否则把结论改小到证据覆盖的范围。

## 4. 旧证据与复用证据

**证据锚点** = 被测版本（commit 或构建号）+ 环境指纹 + 输入数据 + 任务卡判据版本。

以下任一变化，相关证据立即作废：

- 代码、配置或依赖发生变更（纯注释、纯文档变更不影响行为的，需在账本注明理由）。
- 环境重建、升级或换机。
- 夹具、测试数据或账号状态变化。
- 任务卡判据变更（任务卡升版）。

**复用条件（须全部满足）**：

1. 锚点完全相同。
2. 原证据是 A 级，或两类不同通道的 B 级。
3. 复用前对关键断言做一次抽样复算，复算结果记入账本。
4. 不超过原证据的声明范围。
5. 账本标注“复用自 <证据 ID>”，不把复用写成新取证。

**无法确认锚点是否变化时，按已过期处理。** 时间不是唯一标准：昨天的证据可能仍然有效，改过一行代码之后的证据一定失效。外部条件类证据（服务可用、证书、额度、网络）只在当次会话内有效，跨会话必须重取。

## 5. 置信度

置信度只写四档，不写百分比：

| 档位 | 条件 |
|---|---|
| 高 | A 级证据，覆盖声明范围，且经过独立复核 |
| 中 | 1 条 A 级，或 2 条不同通道的 B 级，覆盖主路径 |
| 低 | 单条 B 级，或仅有 C 级推断 |
| 不可判 | 没有证据，或证据已过期 |

规则：

- 置信度是给读者的描述，不改变包结论判定。低置信不能写成“通过（低置信）”，只能写 v1 的未交付-失败/未交付-阻塞（旧八列写未通过/阻塞）。
- 置信度不能跨验收项合并。不能因为 A 项证据很硬，就把 B 项的置信度也抬高。
- 降低置信度的常见原因：样本太少、环境与目标环境不一致、只测了快乐路径、执行者自己复核自己。

## 6. 三个坏例的判法

| 坏例 | 交上来的东西 | 按本文件怎么判 |
|---|---|---|
| 只有截图 | 一张设置页局部截图，结论写“全部设置项正常” | 截图只是单条 B 级证据，且只覆盖一个区域，达不到“全景 B 加局部 B”；结论范围大于证据范围，按 F1 判未通过（证据不足） |
| 证据过期 | 上周构建的测试报告，本周代码已经改过 | 版本锚点变化，证据立即作废（F2）；除非同锚点重取，或复用前抽样复算并记录，否则判未通过 |
| 自报完成 | “已完成，应该没问题”，没有命令、读数和操作路径 | 属于 C 级自述（F3、F4），没有任何 A 或 B 级证据，不能判通过，判未通过 |


## 9. 术语表与等级口径

| 术语 | 一句话解释 |
|---|---|
| AC | 验收项，任务卡里一条可判断真假的完成条件 |
| 用户旅程 | 从用户入口走到结束状态的一条真实路径，不是功能清单 |
| 证据账本 | 07 文件里的逐项表，记录每项的证据、等级、产出者、复核者和状态 |
| 完成审计 | 把“完成定义”逐条映射到 AC、命令、最终构建、读数和证据的表 |
| 独立复核 | 不复用产出者结论，逐 AC 写 supports/does-not-support/unclear 并复跑 A 级命令 |
| 阻塞举证单 | 证明“不是没做，而是当前确实做不了”的结构化记录，含四维尝试、正对照和解锁条件 |
| manifest | 证据包清单，登记文件、SHA-256、字节数、是否跟踪和来源命令 |
| workspace_hash | 取证时受控文件内容的指纹；文件一变，旧证据立即失效 |
| 快慢车道 | 轻验收走快车道，跨模块、不可逆、数据、安全、发布等硬触发必须走全流程 |
| 硬触发 | 任务卡里列出的强制升级条件，命中任意一项就不能走轻验收 |
| 判据 | 给定输入和操作后应得到什么可观察结果；不写“正常”“流畅”这类感受词 |
| gate | 本地完成线入口，依次跑账本、覆盖、清单、范围锁、防绕过和脱敏检查 |
| F1–F6 | 六类假结论：以偏概全、旧证据复用、未跑先断、未验写通过、没试写阻塞、多口径 |

等级口径只有四档：`A` 可独立复算，`B+` 两路现场观察互证，`B` 单路现场观察，`C` 推断或自述。`B+B` 是历史写法，等同于 `B+`；新账本统一写 `B+`。任何等级都不能越过“结论只能比证据小”这条线。
