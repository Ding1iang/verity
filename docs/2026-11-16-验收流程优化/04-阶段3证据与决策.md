## 2. 为什么暂不落 v1.4

- E1 的 8/9 是归档证据，自动预跑只验证“已修问题能读出来”，没有验证“改前能抓住、改后不误伤”的完整前瞻流程。
- 2026-11-15 人工审计曾把 6 条观察项误计为缺陷，说明 E1.2/E1.3 有真实误报风险；当前排除规则只是写在设计里，未在影子批实测。
- R1/R2 的试运行是实验报告，不是带任务卡的真实批次；没有同一批次的漏检/误报/工时三项联合读数。
- 按用户定的四步，第三、四步未完成前落模板会把“纸面覆盖”变成“规则自信”，比不改更糟。

## 3. 决策

- R3：保留 v1.3.5 已落规则；影子期继续记账，不回退。
- E1：保留为影子清单，**不写入模板/检查器**；等真实 UI 批次人工执行一次。

- R2：保留为影子清单；按 K2+K4 两群跑真实批次；组合键无原语时只记未覆盖。
- v1.4：**暂缓**。只有真实影子批达到漏检 ≤1、额外工时 ≤3.5h、误报返工 ≤1，才进入模板/检查器落地。
