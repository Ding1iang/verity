# 03 影子批一任务书（只带清单，不改模板/检查器）

> 状态：待执行 ｜ 目标：用一批真实任务验证 E1 + R1 + R2 + R3 的漏检、工时、误报
> 边界：不改 notes-hap 产品代码；不改 verity 模板/检查器；只把检查清单附在任务书里；发现问题只登记，不修复。

## 1. 选批条件

- 优先选左栏、回收站、空态、弹窗、页面卡、页签或窗口布局有改动的真实批次。
- 该批必须已有明确任务卡/验收项；不能拿纯文档批或纯数据批充数。
- 批前记录：批次名、基线 commit、最终 HAP、窗口形态、数据状态、执行人、开始时间。

## 2. 附加检查清单

### E1 入口与视觉

- [ ] 列出本批受影响入口，每个入口一行（名称、入口位置、默认态是否可见/可点）。
- [ ] 逐项点击，记录可见变化；⛔ 不补造前置证明入口存在。
- [ ] 读控件树 bounds：同层可点击控件两两交集面积 = 0；文本右/下缘 ≤ 父容器；排除透明焦点代理/装饰热区。
- [ ] 对照菜单/Toast/撤销条/空态，同一动作只用一套动词；专有名词按术语表。

### R1 形态×数据

- [ ] 本批选 C2（PC 最大化×满库+页签满）和 C4（平板全屏×满库+页签满）；无平板时用 PC 自由窗口×页签满兜底。
- [ ] 空态改动加 C1（PC 最大化×空库）。
- [ ] 不选的行写“不适用 + 理由”，⛔ 不留空。

### R2 键鼠

- [ ] 受影响模块至少一条纯键盘 AC（Tab/上下/Enter/Esc/Back 顺序写清）。
- [ ] 至少一条鼠标 AC（右键/悬停/点击目标写清）。
- [ ] 组合键先做正对照；无原语记“未覆盖-注入通道无原语”，不算通过。

### R3 不变量

- [ ] 每条 AC 带一个跨区域不变量：当前页是目标 / 计数与内容一致 / 焦点落点 / 跨区域内容一致，并写读数。
- [ ] 不变量不超出本批修复范围；入口类缺陷用“默认态入口可见且可点”。

## 4. 判定

- 漏检 ≤1、额外工时 ≤3.5 小时、误报返工 ≤1：规则进入影子批二，并保留逐条读数。

- 本批不改模板/检查器；所有发现只作为下一阶段输入。
