## 约束与红线

- 不改产品代码；只写本批任务卡、07、evidence 与 blocking-form。
- 07 状态只允许：`通过` / `未交付-失败` / `未交付-阻塞` / `未覆盖`；收口时仍有 `未覆盖`，包结论只能记 `未交付（失败）`。
- 包结论只允许：`通过` / `未交付（失败）` / `未交付（阻塞）`。
- 证据必须真实存在；禁止预写通过；禁止拿旧版本、旧截图、旧日志充当本批证据。
- commit 必须是真实 git 对象，且等于版本锚点或为其祖先；工作区证据要写 `工作区`。
- 设备操作前先 `device-drive.sh probe`；不重置用户数据掩盖问题；首启/空态用夹具，不靠清库。
- 不提交他人改动；不 push 标签；不覆盖已有批次文件。
